Blueprint Studio 1.0.0

The first production release brings seven drawing disciplines, intelligent imports, dependable project files, and professional publishing to Windows.

What's included

A complete visual engineering workspace

Seven diagram types

Network, database, software architecture, workflow, mechanical, electrical, and house floor-plan workspaces.

Intelligent imports

Read-only AWS discovery, spreadsheet inventories, local C# analysis, database metadata mapping, and compatible workflow source.

Professional editing

Multi-selection, resize, rotation, copy and paste, grouping, locking, alignment, distribution, snap-to-grid, layers, and multiple pages.

Workflow generation

Graph validation and compilable asynchronous C# state machines, including complete Visual Studio projects and DI registration.

Reliable documents

Atomic saves, versioned portable files, legacy drawing support, autosave recovery, recent projects, templates, and undo/redo.

Publication output

High-resolution PNG, scalable SVG, multi-page PDF, branded reports, title blocks, legends, and Windows printing.
