Quick start

Blueprint Studio opens with a start center. Choose a network diagram, floor plan, workflow, mechanical drawing, electrical diagram, software architecture, or database diagram. You can also import AWS or spreadsheet inventory, analyze a C# solution, map a database, import a C# workflow, open a recent project, or choose a starter template.

  1. Choose a component from the library.
  2. Drag it into position on the canvas.
  3. Select it and edit its name, address, status, size, rotation, and notes in Properties.
  4. Choose Connect, then select two components.
  5. Choose Save for an editable project or Publish for shareable output.
To return to the welcome choices later, open New and choose Start center.

Professional editing tools

Selection and arrangement

  • Hold Ctrl while selecting to add or remove individual components. Hold Shift to add a component or group.
  • Drag across empty canvas space for marquee selection, or press Ctrl+A to select every visible, unlocked component.
  • Use Edit to copy, paste, duplicate, align, distribute, group, ungroup, or lock the selection.
  • Drag a selected component's handles to resize or rotate it. Snap-to-grid is on by default and can be toggled from Edit.
  • Use the Layers panel to add layers, move selected components, and control visibility or locking.

Connections

Choose Connect and select the first and second component. Double-clicking a component also begins a connection. Select a connection line or label to edit its visible label and flow: none, forward, reverse, or bidirectional. Double-click a connector to add a routing point, then drag its handle around other components. Press Esc to leave connection mode.

Drawing workspaces

Networks and infrastructure

The library includes servers, virtual machines, databases, routers, network switches, firewalls, cloud/internet services, and client devices. Each component can carry a name, IP address or hostname, status, and notes.

Mechanical drawings

Use plates, shafts, bearings, gears, holes, motors, pumps, dimension lines, and center lines. Edit exact width, height, and rotation. Units can switch between millimeters and inches without changing visual scale.

Electrical diagrams

Build with power sources, grounds, resistors, capacitors, inductors, switches, lamps, transformers, junctions, and outlets. Wiring is directionless by default, but labels and flow arrows remain available.

House floor plans

Begin with rooms and walls, then place doors, windows, stairs, beds, sofas, tables, sinks, and toilets. Floor plans default to feet and can convert between feet, inches, and millimeters.

Workflow diagrams and C# generation

Add one Start node, process and action nodes, decisions, and one or more End nodes. Decisions require two outgoing Yes/No paths. Generate C# validates reachability, dead ends, termination, fan-out, and branch labels before producing an asynchronous state-machine class or a complete Visual Studio project.

Import and discover

Analyze C# source

Choose Import → Analyze C# source folder. Blueprint Studio parses source locally and maps controllers, UI/view models, services, repositories, data models, data stores, dependencies, method calls, Entity Framework relationships, API routes, and detected HttpClient flows. Source code is read-only and is not uploaded or modified.

Spreadsheet inventory

Import .csv, .xlsx, or .xlsm files. Map columns to resource name, type, address, status, connections, or notes; choose how to handle duplicate names; and review skipped rows, unknown types, duplicate records, and missing targets before creating the diagram.

Map a database

Choose SQL Server/Azure SQL, PostgreSQL, MySQL/MariaDB, Oracle, or SQLite. Test the connection, load metadata, search the object list, and select what to map. Generated cards include schemas, object types, columns or parameters, data types, nullability, and primary keys. Foreign keys become labeled directional connectors. Access is read-only, and credentials are never saved in the drawing.

Import and refresh AWS

Select a named AWS profile or the default credential chain and choose a region. The importer reads VPCs, subnets, EC2 instances, RDS databases, and load balancers without changing resources or storing access keys. Refresh matches stable AWS identifiers, preserves placement and manual edits, adds new resources, and marks resources no longer returned as offline for review.

Import a workflow

Choose Import → C# workflow state machine to reconstruct a diagram from Blueprint Studio-generated code or compatible C# built around a WorkflowStep enum and switch-based state machine.

Files and publishing

  • Save writes an editable .blueprint.json project.
  • Open restores a saved project; legacy .topology.json files remain supported.
  • PNG produces a high-quality image at 150, 300, or 600 DPI.
  • SVG produces scalable vector output.
  • PDF publishes every project page; Report PDF adds a branded component inventory.
  • Print opens normal Windows printer selection with the selected page setup.

The publishing window supports Letter, A4, Legal, and Tabloid paper; portrait or landscape orientation; legends; title blocks; drawing number; revision; author; approver; and drawing date. Keep the Blueprint project as the editable source after publishing.

Document reliability and templates

Projects save atomically so an interrupted write does not leave a partial document. While a drawing has unsaved changes, a recovery copy is written every 30 seconds. After an unexpected shutdown, the next launch offers to restore it. Saving or intentionally discarding changes removes the recovery copy.

The Open menu lists up to ten recent drawings. Three built-in templates are available, and any current drawing can be saved as a portable .blueprint-template.json file. Blueprint Studio asks whether to save, discard, or cancel before replacing or closing unsaved work.

Navigation, pages, and themes

Use + and − to zoom, Fit to show the full drawing, and scrollbars for larger canvases. Use Pan, hold Space, or drag with the middle mouse button to move around. Hide or resize the library and properties panels to give the canvas more room.

Project pages appear along the bottom. Add, select, or delete pages there; each page keeps its own components, connectors, paper setup, legend, and title-block visibility. In Settings, choose Light, Medium, or CoreNuc Dark. Theme changes apply immediately and are remembered.

Accessibility and diagnostics

Primary commands are reachable with Tab and Shift+Tab. Press Alt to reveal access keys. A high-visibility focus outline identifies the active control, and status changes are announced to assistive technology. Local structured diagnostics are retained for 14 days in the Blueprint Studio application-data folder. They remain on your computer unless you choose to share them and do not intentionally contain drawings or AWS credentials.
