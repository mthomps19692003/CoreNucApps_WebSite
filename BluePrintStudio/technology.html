Under the canvas

One engine. Seven disciplines.

Blueprint Studio is a native Windows application built around a shared, versioned drawing model and a consistent professional editing pipeline.

Foundation

Native Windows engineering

Built with C# on .NET 10 and Windows Presentation Foundation, Blueprint Studio combines a responsive desktop interface with local file access, printing, accessible controls, and high-quality vector and raster rendering.

Shared document model

Every workspace uses the same versioned components, connectors, pages, layers, selection, undo, saving, and publishing behavior.

Purpose-built renderer

Vector-based component styles, routed connections, resize and rotation handles, automatic bounds, and page-aware output remain crisp at every scale.

Portable projects

Editable JSON documents are straightforward to store, back up, move between computers, and preserve independently of the application.

Import intelligence

Connect to the source—on your terms

AWS infrastructure

The official AWS SDK reads VPCs, subnets, EC2 instances, RDS databases, and load balancers using your configured identity. Refresh reconciles stable resource IDs while preserving manual edits.

C# analysis

Roslyn builds a cross-project compilation locally to map APIs, services, repositories, models, dependencies, method calls, Entity Framework relationships, and detected HTTP flows.

Database metadata

Provider-specific connectors discover SQL Server/Azure SQL, PostgreSQL, MySQL/MariaDB, Oracle, and SQLite objects through read-only metadata access.

Spreadsheet inventories

CSV, XLSX, and XLSM files can be previewed, mapped, validated, de-duplicated, classified, and transformed into connected infrastructure diagrams.

Security and privacy

No account. No telemetry. No automatic upload.

Code and spreadsheet analysis happen locally. Database credentials remain in memory only for the requested connection and are not written to project files or diagnostics. AWS access keys remain with the configured AWS identity provider.

Full privacy policy

Reliability

Designed for work worth keeping

Safe saving

Atomic document writes avoid leaving a partially written drawing if a save is interrupted.

Recovery

Unsaved work creates a local recovery snapshot every 30 seconds and can be restored after an unexpected shutdown.

Compatibility

Format versioning upgrades older documents and protects newer, unsupported files from accidental changes.

Accessible by design

Built for keyboard, screen reader, and display scaling

Primary commands are keyboard reachable, focus is highly visible, status updates are announced to assistive technology, and the canvas and page controls expose meaningful accessible names. Light, Medium, and CoreNuc Dark themes support different workspace preferences.
