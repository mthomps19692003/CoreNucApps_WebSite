Use this guide to prepare an event, run the live auction, check out bidders, settle with consignors, and close the auction safely.

CoreNuc Auction App — Lazy Lions Edition supports a simple one-computer setup or several workstations connected over a trusted local network.

Quick Start

  1. Create the auction with its date, location, buyer's premium, and sales-tax rate.
  2. Register consignors, build the catalog, and print labels, intake sheets, or catalogs.
  3. Register bidders, document buyer agreements and eligibility, and print bidder cards.
  4. Use Live Auction to record each sold, passed, withdrawn, or no-sale lot.
  5. Open bidder invoices, accept payments, finalize checkout, and print or save receipts.
  6. Release paid purchases for pickup or shipping with staff and recipient confirmation.
  7. Review consignor settlements, approve totals, and record seller payments.
  8. Review reports, resolve blockers, reconcile cash drawers, and close the auction.

For one computer, leave the app in Local Only mode. For multiple computers, choose one host and connect every other workstation before the auction begins.

What the App Does

CoreNuc Auction App — Lazy Lions Edition keeps the complete in-person auction workflow in one Windows application. It manages intake, cataloging, buyer agreements, live results, invoices, payments, pickup, communications, settlements, analytics, privacy requests, staff access, and audit history.

Records are stored locally on each computer. A one-computer auction requires no network setup. For a larger operation, a host synchronizes dedicated registration, auction, and checkout workstations across the local network without requiring internet access.

The Dashboard shows the active auction, lot and bidder counts, lots sold, gross hammer total, auction progress, and a preparation checklist.

First-Time Setup

The first-run assistant collects the business name and contact details used on documents, tax label and default rates, receipt-printer settings, the first auction, the first administrator, and the backup folder. It creates an initial verified backup before normal operation begins.

Optional practice auction

The assistant can create reserved training records so staff can rehearse cataloging, bidder registration, live entry, checkout, and settlement. Remove the practice auction from Settings when training is complete.

Create the auction event

Open Auctions. Enter the event name, date, location, buyer's premium percentage, and sales-tax rate for the event location. Select Create event. The newest event becomes the active event used for totals and checkout.

Check the Dashboard

Confirm that the correct event name, date, and location appear at the top. Create the correct event before entering auction-night transactions if anything is wrong.

Choose one or several computers

For one computer, no network setup is needed. For several computers, follow the networking section below and connect each workstation before work begins.

Never place the auction.db database in a shared Windows folder. Each computer uses its own local database and communicates through Lazy Lions synchronization.

Set up staff access

The first time the app opens, create the administrator account. Give every worker a unique username and 4–8 digit PIN. In Settings, create the separate manager approval PIN used for protected financial corrections.

Prepare for the Auction

Register consignors

Open Consignors. Give each seller a unique number and enter the seller's name, phone, email, address, and commission percentage. A consignor must exist before a lot can be assigned to that seller number.

Enter auction lots

Open Lots. Enter a unique lot number, description, registered seller number, reserve, category, condition, dimensions, storage location, and optional photo. Use seller-name lookup when the number is not known.

Selected photos are resized when needed and copied into the local CatalogPhotos folder. They are not synchronized to other workstations or included in database-only backups, so protect that folder separately.

Print preparation materials

On Lots, choose Print labels for lot labels or Print inventory for the full catalog. Review the selected printer, paper, and orientation before printing.

Register bidders

Open Bidders. Assign a unique bidder number and enter the buyer's name, phone, email, and address. Search, filter, edit, archive, restore, or delete supported records from the list.

Print bidder cards

Select a bidder and choose Print selected bidder card. Ask the bidder to hold the number up clearly when bidding.

Catalog Tools

Create several lots together

Open Lots and select Catalog tools. Choose a consignor and starting lot number, then drop several photos into the window, select files, import from a camera or device, or add blank rows. One draft lot is created for each photo.

Complete catalog details

Edit descriptions, category, condition, dimensions, storage location, and photo assignments directly in the draft grid. Default values can be applied to the batch before all draft lots are created together.

Duplicate or renumber lots

Duplicate a selected lot when similar items share most catalog details. Use Renumber ready lots to assign a new starting number and increment without changing completed sale records.

Search and archive records

Auction, consignor, lot, and bidder lists now include search, status filters, edit controls, archive and restore, and guarded deletion. Archive records that must remain in history but should no longer appear in normal working lists.

Buyer Agreements and Eligibility

Select a bidder and open Buyer agreement. Record the exact auction terms and version accepted, signature confirmation, signed name, deposit status, card-on-file status, and ID-verification status.

Record status only for identification and card assurance. Never enter an ID number, full card number, or card security code.

Tax-exempt bidders can have a PDF, PNG, or JPEG certificate attached inside the local database. Attachments are included in encrypted database backups and should be added on the host in a multi-computer auction.

Use bidding restrictions for deposit-required, manager-approval, or suspended bidders. Internal staff notes are not printed for the bidder. The registration list shows whether required agreement information is complete.

Run the Live Auction

Record a sold lot

Open Live Auction and confirm the large lot number and description match the item on the block. Enter the winning bidder number and hammer price, then select Sold or press Enter. The result saves immediately and the next ready lot appears.

Record other outcomes

Choose Passed if bidding may return later, No sale when the item did not sell, or Withdraw when the auctioneer removes it. Completed lots are skipped while moving through the catalog.

Navigate the catalog

Use Previous and Next to move between ready lots. Recent Activity shows the latest completed lots, bidder numbers, and hammer prices.

Correct the latest result

Select Correct last only when the most recent result is wrong. The lot returns to Ready so it can be entered again. The correction remains visible in audit history.

Live Auction Command Mode

Select Open command mode for a focused auction-clerk workspace. It shows the current lot and photograph, next lot, ready count, workstation connection, backup status, bidder confirmation, and last recorded result.

Default live shortcuts are Enter for Sold, F6 for Passed, F7 for No Sale, F8 for Withdraw, Page Up and Page Down for lot navigation, and Ctrl+Z for Correct Last. Administrators can assign supported F2–F12 or Ctrl/Alt shortcuts in Settings; every action must use a different shortcut.

Before bidding, verify the connection and backup badges, test the keyboard workflow, and confirm the next lot with the auctioneer. Command mode does not bypass bidder eligibility, sale validation, manager approval, or audit controls.

Check Out a Bidder

Open the cash drawer

Before taking cash, enter the opening cash count and select Open in the Cash Drawer area. Check and card payments can be recorded without an open drawer, but cash payments cannot. Each workstation maintains its own drawer session.

Open and verify the invoice

Enter or scan the bidder number and open the invoice. Confirm the bidder and every purchased lot. Opening the invoice gives that workstation temporary control so another cashier cannot finalize the same bidder at the same time.

Review charges and taxes

Review the hammer total, buyer's premium, sales tax, adjustments, invoice total, and balance. Tax is omitted for bidders marked tax exempt. Charges and discounts require a reason and remain in audit history.

Accept payment

Choose Cash, Check, or Card; enter the amount and a useful reference, such as the check number or last four card digits; then select Add. For split payment, add each part separately. The app prevents payments above the host-authoritative balance.

Finalize and print

An invoice can be finalized only when its balance is zero. Finalization protects it from ordinary edits. Printed receipts include lots, adjustments, payments, refunds, references, invoice status, and balance.

Refund or correct a finalized invoice

For a refund, select the original payment, enter the amount and reason, and refund that payment. To change a finalized invoice, enter the manager PIN and a detailed reason, then reopen it. Original transactions are retained.

Close and reconcile the drawer

At the end of a cashier shift, count physical cash, enter the counted amount, and select Close & reconcile. Compare Expected, Counted, and Over/Short before leaving the workstation.

Pickup and Item Release

Open a paid buyer

Open Pickup & release and search by bidder number, name, phone, or email. The queue prioritizes paid buyers with waiting or partially released items. A controlled workstation lock prevents conflicting releases.

Plan storage or shipping

Select purchased lots, mark items that require shipping, and save their storage locations. The screen shows payment-required, awaiting-pickup, partial-pickup, and fully released status.

Release selected items

Only items on a paid invoice may be released. Record the pickup person or shipping recipient, whether government-issued ID was checked, a typed signature, confirmation note, or tracking number, and the pickup or ship date. The app records the signed-in staff member and time automatically.

Settle with Consignors

Open the seller's settlement

Open Settlements, select a consignor, and open the selected settlement. Review all sold, passed, withdrawn, and no-sale lots. Only one workstation can control a seller's settlement at a time.

Review proceeds and fees

Gross sales and commission are calculated automatically. Add lot fees, no-sale fees, advertising charges, or another deduction only when needed. Include a clear reason for every deduction.

Approve and pay

Enter the manager PIN and approve the settlement after checking its totals. Choose the payout method, enter the check or transaction number, and mark the consignor paid. Approved and paid settlements are protected from ordinary changes.

Print or correct a statement

The printed statement lists the seller, lots, commission, deductions, net proceeds, and payout reference. To correct an approved or paid settlement, enter the manager PIN and a detailed reason, then reopen it.

Review Reports and Close the Auction

Run the closeout review

Open Reports and select Refresh. Review Sales, Invoices, Payments, Tax, Unsold, Settlements, and Drawers. The summary shows hammer, premium, tax, collected payments, outstanding balances, and consignor proceeds.

Understand review levels

A Blocker must be resolved before closeout, such as an unpaid or unfinalized invoice, unpaid consignor, open drawer, or unsynchronized change. A Warning needs manager review. Information identifies items such as unsold inventory.

Export reports

Choose a destination folder to create separate CSV reports, a multi-sheet Excel workbook, and a printable PDF summary. Reports include an as-of timestamp. Accounting exports and operational analytics are available separately for specialized review.

Perform final closeout

For a multi-computer auction, close only from the host after every station is connected and finished. Enter the manager PIN, resolve all blockers, and close the auction. The final package contains reports, a verified database backup, and a checksum manifest.

Reopen only when necessary

A closed auction is read-only for catalog, sale, checkout, settlement, and import changes. To make an approved correction, enter the manager PIN and a detailed reason, then reopen the auction.

Operational Analytics and Accounting Exports

Review operational performance

From Reports, open Operational analytics to review sell-through rate, average hammer, average bidder spend, registration-to-purchase conversion, checkout duration, and unsold inventory.

Detailed tabs show category performance, below-reserve sales, revenue per consignor, bidder spending, checkout time, payment-method distribution, and unsold-inventory aging. Export creates separate CSV files for further analysis.

Create accounting schedules

Accounting exports creates UTF-8 CSV schedules for sales, premiums, taxes by jurisdiction, refunds, payment methods, deposits, liabilities, commissions, settlement payments, and drawer over/short. A README explains the files and a SHA-256 manifest supports later verification.

Communications Center

Open Communications from the navigation or from a selected bidder or consignor. The app can prepare registration confirmations, winning-bid summaries, invoices, payment receipts, pickup reminders, unpaid-balance reminders, and consignor settlement statements.

Review the recipient, subject, and body before opening an email draft or copying the message. The app opens the default Windows email program; it does not send the message itself. Staff choose Send in that program.

Consent is checked for the relevant channel. After using the email application, mark the prepared history entry Sent, Failed, or Cancelled. Failed and cancelled outcomes require a reason, and the communication history records the staff member and workstation.

Privacy and Customer Data

Open Privacy & data to save the public privacy-policy URL, choose a 1–25 year retention period, find bidder or consignor records, export one customer's information as JSON, and review communication consent.

Consent history is append-only. Record each grant or withdrawal with its channel, purpose, source, staff member, time, and workstation.

Eligible archived customer records can be anonymized only after a manager provides a reason, confirms legal and retention obligations permit it, and enters the approval PIN. Transaction totals and audit integrity remain available.

This page also configures password-protected encrypted backups. Keep the backup password separately in a secure place; it is required to restore on a replacement computer.

Import Existing Records

Create or prepare a package

Open Import Data and create a blank template. Use separate CSV files, a ZIP containing them, or one Excel workbook with sheets named Auctions, Consignors, Bidders, Lots, Sales, and Payments.

Validate before changing data

Choose the completed package, decide whether matching numbers should be skipped or updated, and whether balanced historical invoices should be closed. Select Validate & preview. Preview does not alter live data.

Correct errors and import

Fix every reported error in the source files and validate again. Import becomes available only when no errors remain. Lazy Lions creates a verified backup first and rolls back the complete import if any record fails.

Multi-computer auctions

Run imports on the host. Imported records are then published to connected workstations. Each package receives a fingerprint to prevent accidental duplicate imports.

Set Up Several Computers

On the host computer

Open Settings. Leave the default port unless a network administrator instructs otherwise. Enter a shared sync key and select Start Auction Host. Keep the host powered on until every workstation is finished and up to date.

On every other computer

Open Settings. Enter the address shown by the host, such as http://AUCTION-PC:5127, and the exact same sync key. Select Connect workstation.

Connected

Accepted changes can move between this station and the host.

Synchronizing

The station is sending or receiving changes. Wait for Connected.

Offline

Sales remain queued locally. Do not finish checkout until reconnected.

Sync Error

Read the message, verify the address and key, then reconnect.

Use networking only on a trusted private network. Do not share one SQLite database file between computers.

Back Up or Restore Auction Data

Automatic protection

The app creates a verified database backup every 30 minutes and when it closes. Settings shows the latest backup time and storage folder. The newest 30 automatic copies are retained.

Enable encrypted backups

In Privacy & data, choose a backup password of at least 12 characters. New automatic and manual backups use AES-256 authenticated encryption and the .llabackup extension. The password is protected locally by Windows, but it must be kept separately for disaster recovery.

Create or copy a backup

Select Back up now for an immediate local copy. Select Save copy to place a verified backup on a USB drive or another computer. Wait for confirmation before removing the drive.

Restore a backup

In Settings, select Restore and choose an encrypted CoreNuc backup or a legacy ZIP backup. Configure the same password first when restoring on a replacement computer. The app verifies the checksum and database health, stops network services, and creates a safety copy before restoring.

Recovery after an interrupted session

If the previous session did not close safely, review Recovery Mode before continuing. Compare the last recorded sale with the auctioneer's written record, inspect pending offline changes and open financial work, then resume or restore a verified backup.

Replace a failed host safely

Stop bidding, make sure the original host is offline, restore the newest verified backup on the replacement, reconcile later sales, then reconnect one workstation at a time. Wait for Connected and zero waiting changes before adding another station.

Staff Sign-In and Security

Each worker should use a unique username and 4–8 digit PIN. Give each person only the access required for the job. Five incorrect PIN attempts temporarily lock the account for five minutes.

Registration Clerk

Registers bidders, records contact and tax-exempt details, and prints bidder cards.

Catalog Clerk

Creates consignors and lots, adds descriptions and photos, and prints labels or inventory sheets.

Auction Clerk

Records winners, hammer prices, passed lots, withdrawals, and no-sales.

Cashier

Opens invoices, accepts payments, manages the cash drawer, and prints receipts.

Manager

Supervises operations, approves corrections, reviews reports, and closes the auction.

Administrator

Controls staff accounts, custom roles, networking, hardware, backups, updates, and settings.

Custom roles

Administrators can combine specific permissions for real jobs that do not match a built-in role. Keep permissions narrow and describe the role's purpose clearly.

Locking and switching users

Select the signed-in name at the lower left to lock the app and let the next worker sign in. The app also locks after inactivity.

Audit Center

Managers and administrators can search who signed in, entered sales, handled payments, approved corrections, or changed staff access. Export CSV when an auditor or accountant needs a copy.

Scanning, Printing, Returns, and Support

Barcode and QR scanning

Connect a USB scanner in keyboard mode. Select Scan barcode / QR, then scan a Lazy Lions lot label, bidder card, or QR code. Lot codes open the ready lot; bidder and invoice codes open Checkout.

Design and print documents

In Settings, enter the auction company's printed name, address, phone, and receipt footer. Lot labels and bidder cards include Code 39 barcodes. Receipts show lots, premium, tax, payments, and remaining balance.

Receipt printer and cash drawer

Install the printer in Windows first. Enter its exact Windows name in Settings, choose the paper-cut and drawer options, save, then use Test Receipt and Test Drawer. Without a configured receipt printer, Lazy Lions uses the normal Windows print dialog.

Returns and buyer transfers

Open the buyer invoice in Checkout and reopen any affected finalized invoice or settlement. Enter the lot, a specific reason, and the signed-in manager PIN. For a transfer, also enter the receiving bidder. The app recalculates both buyers and retains synchronized history.

Updates and support packages

Administrators can configure a secure CoreNucApps update feed. Downloads are checksum-verified before Windows Installer starts. A support package contains system and database-health details but excludes auction records, customer data, payments, PINs, and sync keys.

Accessibility and Display Support

The application supports keyboard-only workflows with visible focus, automatic accessible names for common controls, text-based status messages, screen-reader-friendly labels, scroll-safe windows, and Windows high-contrast themes.

Layouts are designed to remain usable at 1024×768 and at Windows display scaling up to 200%. Scrollbars may appear so actions remain reachable. Per-monitor DPI awareness keeps the application responsive when moved between displays with different scaling.

Press Windows+Ctrl+Enter to start Narrator. Use Tab and Shift+Tab to move between controls, arrow keys in lists and tables, Enter or Space to activate controls, and Escape to close supported dialogs.

Troubleshooting and Safe Shutdown

A workstation will not connect

Confirm the host is running, both computers are on the same local network, the address and port are correct, and sync keys match exactly. If Windows Firewall asks, allow Lazy Lions on private networks.

A bidder, lot, or seller number is rejected

Numbers must be unique. Search the appropriate list for the existing record. The host keeps the first accepted record if two computers try to create different records with the same number.

The wrong lot was sold

If it was the latest transaction, use Correct Last and enter it again. For an older result, stop using the related invoice and ask a manager to review the audit history before checkout.

An invoice or settlement is in use

Another workstation controls that financial record. Finish or leave it on the other station, then try again. If a station lost power, wait about one minute for the lock to expire.

An import will not continue

Read the Detail column, correct the workbook or CSV, and validate again. Import stays disabled while errors remain. A package already imported must be corrected so its content and fingerprint change.

Closing the application

Select the close button once. Synchronization services may take a moment to stop. Do not turn off the host until every workstation shows Connected and zero changes waiting.

Auction-Day Opening and Closing Checklist

Before doors open

  • Confirm the active auction, buyer's premium, and tax rate.
  • Start the host, connect each workstation, and confirm zero waiting changes.
  • Create a manual backup and test a bidder card, lot label, receipt, and statement.
  • Confirm that the manager approval PIN works.

Before bidding begins

  • Confirm consignors and lots are complete and all import errors are resolved.
  • Check lot order and reserves.
  • Verify the Live Auction keyboard workflow and Recent Activity list.

Before checkout opens

  • Open each cash drawer with a counted amount.
  • Confirm check and card reference procedures with staff.
  • Remind cashiers not to finalize while offline.

Before leaving

  • Finalize or identify every unpaid invoice and reconcile every drawer.
  • Review consignor payouts and exceptions.
  • Confirm all stations are connected with zero changes waiting.
  • Create a final verified backup, save a second copy, close workstations, then shut down the host.

The winning bid before premium and tax.
