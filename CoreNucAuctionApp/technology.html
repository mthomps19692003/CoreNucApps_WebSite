Technology

CoreNuc Auction App — Lazy Lions Edition uses a modern Windows desktop stack for responsive auction operation, dependable local records, local-network teamwork, controlled financial workflows, accessibility, reporting, encrypted backups, recovery, and Microsoft Store packaging.

Core Application Stack

.NET 10

The application targets .NET 10 for Windows and uses a self-contained release build so customers do not need to install .NET separately.

Windows Presentation Foundation

WPF provides the native Windows desktop application framework, window management, controls, data grids, printing integration, and input handling.

C#

C# powers auction rules, persistence, financial calculations, synchronization, imports, reports, backups, printing, updates, and security services.

XAML

XAML defines the dashboard, catalog, live auction, checkout, settlements, reports, staff tools, settings, help content, shared styles, and visual resources.

Supported Platform

  • Windows Desktop
  • Windows x64
  • .NET 10
  • WPF
  • Self-Contained Installer
  • Microsoft Store MSIX
  • Per-Monitor DPI
  • Local-First Operation

Local Data and Persistence

SQLite

A local SQLite database stores auctions, consignors, bidders, lots, results, invoices, payments, settlements, staff records, audit history, and synchronization state.

Microsoft.Data.Sqlite

The official .NET data provider executes schema creation, migrations, queries, transactions, indexes, and integrity checks.

SQLitePCLRaw

The bundled native SQLite runtime supports dependable deployment without requiring a separate database server installation.

Transactional Safeguards

Financial operations, imports, corrections, and synchronized changes use database transactions and validation so related updates succeed or fail together.

Local-Network Synchronization

ASP.NET Core

The designated auction computer can host a lightweight local service for other Lazy Lions workstations on the trusted network.

SignalR

ASP.NET Core SignalR coordinates workstation connections and distributes auction changes between the host and connected clients.

Queued Changes

Each workstation keeps its own database and can queue supported changes while temporarily offline, then synchronize when the connection returns.

Conflict Controls

Unique record keys, host-authoritative financial totals, versioned records, and temporary invoice or settlement locks help prevent conflicting work.

Security and Audit

Role-Based Access

Built-in and custom roles limit access to auction setup, cataloging, registration, live entry, checkout, settlements, reports, imports, settings, and corrections.

Protected Credentials

Staff PIN credentials and the separate manager approval PIN protect sign-in and higher-risk financial actions without storing plain-text PINs.

Audit Trail

Security and operational events retain the person, role, action, record type, detail, time, and workstation needed for review.

Safety Locks

Temporary record locks prevent two checkout or settlement workstations from editing the same financial record simultaneously.

PBKDF2 Credential Hashing

Staff and manager PINs use per-credential random salts, PBKDF2-SHA-256 derivation, and fixed-time verification instead of plain-text storage.

AES-GCM Backup Encryption

Optional encrypted backups use AES-256-GCM with PBKDF2-SHA-256 key derivation, authenticated metadata, and a Windows-protected local password configuration.

Documents, Reports, and Hardware

Windows Printing

WPF document and print services generate lot labels, inventory sheets, bidder cards, receipts, consignor statements, and printable auction documents.

Receipt Printers and Drawers

Windows printer integration and supported raw printer commands enable receipt output, paper cutting, and printer-connected cash-drawer operation.

Barcode and QR Input

Keyboard-mode scanners can read Lazy Lions lot labels, bidder cards, invoice codes, and supported QR payloads without a proprietary scanner driver.

CSV, Excel, and PDF

Import and reporting services work with common auction-data formats and generate closeout reports, PDF receipts, analytics, and accounting schedules.

Catalog Photo Processing

WPF imaging decodes supported formats, scales large images to a practical maximum, and creates normalized JPEG copies in the local catalog-photo folder.

Windows Email Drafts

Customer messages are generated locally and opened in the default Windows email application for staff review and manual sending.

Backup, Import, and Diagnostics

Verified Encrypted Backups

Automatic and manual database backups include checksums and manifests, support optional authenticated encryption, retain rotating copies, and create a safety backup before restore.

Import Validation

CSV, ZIP, and Excel imports are normalized, validated, previewed, fingerprinted, backed up, and applied transactionally.

Closeout Packages

Final closeout combines reports, a verified database backup, and a checksum manifest for organized record retention.

Privacy-Aware Diagnostics

Support packages report application, system, database-health, and sync status while excluding auction records, customer data, payments, PINs, and sync keys.

Interrupted-Session Recovery

A session marker detects unsafe shutdown and builds a recovery snapshot with the latest sale, pending changes, connection state, open financial work, and newest verified backup.

Privacy Operations

Dedicated services support retention configuration, append-only consent history, customer JSON export, eligibility checks, and manager-approved anonymization.

Accessibility and Windows Integration

UI Automation

Accessible names, control types, states, labels, and status announcements support Narrator and Windows accessibility inspection tools.

Keyboard and Focus

Shared visible-focus styling, documented shortcuts, predictable tab order, and scroll-safe dialogs support keyboard-only operation.

High Contrast

Windows contrast-theme detection and text-plus-symbol statuses keep connection, warning, paid, and completion states understandable without relying on color alone.

Responsive Desktop Layout

Minimum-size and scroll behavior, PerMonitorV2 DPI awareness, and scaling validation support 1024×768 displays and Windows scaling through 200%.

Testing and Release Engineering

xUnit

Automated tests cover data, migrations, imports, invoices, settlements, synchronization, security, backups, recovery, privacy, communications, agreements, pickup, catalog tools, analytics, accessibility, performance, and production readiness.

WiX Toolset

WiX builds the Windows MSI and customer setup executable for per-machine installation, upgrades, Start menu integration, and managed deployment.

Microsoft Store MSIX

A separate Store pipeline builds the registered CoreNuc Auction App package, validates Partner Center identity and assets, and delegates application updates to Microsoft Store.

Self-Contained Publishing

The x64 package bundles the application, .NET desktop and ASP.NET runtimes, and native SQLite components.

Signing and Verification

The release pipeline supports Authenticode signing, RFC 3161 timestamps, signature verification, SHA-256 hashes, and checksum-verified automatic updates.
