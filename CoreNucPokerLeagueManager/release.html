Latest Release

Release notes for the newest CoreNuc Poker League Manager build, including the changes most useful to tournament hosts and league organizers.

CoreNuc Poker League Manager 2.3.0.0

Version 2.3 delivers a more complete tournament-night experience from player arrival through the final recap, with new formats, guided setup, player-facing information, stronger recovery, and polished sharing.

Version 2.3.0.0
Build 2300
Package Date October 5, 2026
Primary Platform Windows

What Changed

Tournament Formats

Six ways to run the event

Run Standard, Fixed Bounty, Progressive Knockout, Mystery Bounty, Satellite, and Charity tournaments with format-aware tracking.

Player Arrival

RSVP and check-in

Track invited, going, waitlisted, declined, and checked-in players before play begins, then confirm seating as the field arrives.

Player Companion

A QR page for every player

Print a QR code so players can follow their seat, blinds, average stack, High Hand, bounty board, payouts, and live standings.

Smart Builder

Build for the night you want

Generate blinds around the target duration, field size, starting stack, pace, breaks, and color-up points.

Preflight and Recovery

Prepare and protect live play

Verify blinds, seating, payouts, chips, Phone Control, TV display, sound, and backups, then recover complete live state after a restart.

Presentation and Recap

Brand the room and share the finish

Apply display themes and league branding, then export an image or PDF recap with results, prizes, High Hand, knockouts, entries, prize pool, and standings.

Recent Foundation Improvements

  • Game Setup, Players, Rounds, Prizes, Chips, Tables, Saved Games, and tournament screens now use clearer actions, status messages, keyboard focus, and more consistent layouts.
  • Player pages include status, career statistics, and tournament history; High Hand payment and current-hand tracking are available on desktop and Phone Control.
  • Settings includes Check Health and Safety Backup. Imports create a safety backup first, the five newest safety backups are retained, and structured local error logs are retained for 14 days.
  • Database integrity checks, duplicate repair, safer transactional updates, and expanded automated testing improve release reliability.
  • An app-wide Windows right-click menu provides quick access to navigation, timer controls, rounds, undo, tables, player actions, displays, and full screen.

Included App Areas

  • Texas Holdem game setup for players, rounds, chips, buy-ins, add-ons, rebuys, prizes, and tables.
  • Live tournament display with round timer, blind levels, antes, recent actions, and tournament controls.
  • Player action tools for rebuys, add-ons, bust outs, receipts, restores, and undo support.
  • TV Browser Display for showing selected tournament screens on another browser on the same home network.
  • Secure paired Phone Control for trusted local-network tournament control from a phone.
  • Tables and seating tools for assigning seats and balancing active players.
  • Player stats, league standings, settlement reports, and game details review.
  • Player career history, High Hand tracking, and corrections to completed-game totals.
  • Tournament templates for recurring leagues and starter game presets.
  • Settings for prize formulas, display options, receipts, sounds, database health checks, safety backups, and protected imports.

Packaging Notes

The latest Windows package is prepared as a Microsoft Store style package for CoreNuc Poker League Manager. Store licensing and purchase handling are managed through the Microsoft Store listing.

The packaged artifact for this release uses version 2.3.0.0 for the Windows x64 MSIX package.

Known Notes

  • The desktop app remains the primary tournament display and source of truth.
  • The TV Browser Display and Phone Control should be used only on trusted local networks.
  • Phone Control is hosted by the Windows desktop app, opened from a phone browser on the same network, and protected by a six-digit pairing code.
  • The local-network Club Hub experience is included through Player Companion. Public internet hosting requires a separately operated compatible relay, hosting account, deployment, security policy, and service terms.
