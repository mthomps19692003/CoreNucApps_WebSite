CoreNuc Poker League Manager

Designed for home poker leagues running Texas Holdem tournaments, CoreNuc Poker League Manager helps organizers manage live poker events with confidence, structure, and ease.

Get Support

About the App

CoreNuc Poker League Manager is built for home poker hosts, league organizers, and tournament directors who need a simple way to manage Texas Holdem tournaments. The app helps keep games organized by tracking players, tables, blind rounds, buy-ins, rebuys, add-ons, payouts, phone-based tournament actions, and tournament progress from one central application.

Whether you are running a casual poker night, a recurring league event, or a structured multi-table tournament, this application provides the tools needed to build reusable tournament templates, run the clock, confirm live actions, and keep the tournament moving smoothly.

Key Features

Tournament Setup

Create and configure Texas Holdem tournaments with blind levels, starting chips, round times, breaks, payout structures, and reusable templates.

Player Management

Track registered players, seating assignments, table movement, eliminations, and tournament standings.

Buy-ins and Add-ons

Manage buy-ins, rebuys, add-ons, prize pools, and player payments during live tournament play.

Live Tournament Clock

Display current blinds, upcoming blinds, timers, breaks, and tournament status for players and organizers.

Phone Browser Remote

Pair a phone with a six-digit code, then securely control the clock, rounds, player actions, and High Hand tracking from the same private network.

Auto Rounds And Prize Preview

Generate round structures, preview calculated payouts, and apply prize changes with more confidence.

Safer Live Actions

Confirmation prompts and guardrails help prevent accidental bust outs, add-ons, rebuys, restores, and in-progress exits.

League Tracking

Review player history, career results, league standings, High Hand status, and correct completed-game totals when needed.

Data Safety

Check database health, create rotating safety backups, protect imports automatically, and rely on structured local error logs.

Who It Is For

  • Home poker leagues
  • Texas Holdem tournament hosts
  • Recurring poker night organizers
  • Charity or private poker tournament directors
  • Players who want a more professional tournament experience
