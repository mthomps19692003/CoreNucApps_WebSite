Home Maintenance Manager

Technology

A cross-platform, local-first application built to keep home information useful and portable.

.NET 10Modern application runtime
.NET MAUIShared cross-platform interface
SQLiteOn-device structured storage

Cross-platform foundation

The app uses C# and .NET MAUI with targets for Windows, Android, iOS, and Mac Catalyst. Shared layouts and controls provide a consistent experience while respecting each platform.

Local data model

SQLite stores maintenance, property, room, utility, preparedness, project, cost, binder, and checklist records in the app's local data area. Device storage also holds imported property documents and generated exports.

Built-in intelligence

Inspection analysis, home-record questions, and maintenance predictions run with local rules and data. This keeps the core intelligence features available without an external AI account.

Documents and reporting

The app can organize supporting property documents and create PDF or spreadsheet exports for records that need to be reviewed, archived, or shared.

Public preparedness data

An optional hurricane-context feature requests public disaster-declaration information from the OpenFEMA API. Built-in preparedness guidance remains available when that service cannot be reached.
