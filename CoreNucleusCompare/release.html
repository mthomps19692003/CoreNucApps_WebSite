Version 1.1.0 · Guided Compare

A clearer workspace, faster explicit rescans, broader format support, and stronger automation and accessibility.

What's new

  • First-run onboarding and an expanded in-app Help Center.
  • Cleaner workspace navigation and contextual actions for selected results.
  • Search, advanced filters, previous and next difference navigation, and row actions.
  • Persistent deep-hash caching with content fingerprints for faster rescans.
  • Searchable file differences plus Excel, HTML, CSV, and JSON exports.
  • Semantic JSON and XML comparison and TAR, TGZ, and GZIP archive support.
  • Profiles, scheduling, automation dashboards, searchable logs, and enterprise policy support.
  • High-contrast resources, improved keyboard focus, and F1, F5, and Ctrl+F shortcuts.

Safety

Comparison remains read-only. External-change monitoring marks results stale but never starts an automatic rescan. Enterprise policies can restrict roots and disable file changes, recycling, or automation.

Known limitations

  • PDF comparison is text and page-metadata aware; it does not rasterize pages for visual comparison.
  • Proprietary binary formats use byte-block comparison unless a dedicated handler is available.
  • Release packages must be signed with an organization-controlled certificate before distribution.
