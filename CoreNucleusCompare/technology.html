Core Nucleus Compare

Technology

A native Windows comparison workspace built for detailed inspection, safe operations, and repeatable workflows.

.NET 10Modern Windows application runtime
WPFNative desktop interface
Local-firstDirect file and folder analysis

Windows desktop foundation

Core Nucleus Compare is built with C#, .NET 10, WPF, and Windows desktop services. The interface supports keyboard operation, visible focus, display scaling, and high-contrast resources.

Comparison engine

Quick mode compares practical file metadata, while deep mode calculates content fingerprints. A persistent cache can reuse validated hashes, and file-system monitoring identifies when results need an explicit rescan.

Document and archive support

Dedicated handlers provide searchable text and structured comparison for supported formats, including Excel workbooks, PDF text and page metadata, JSON, XML, TAR, TGZ, and GZIP. Other binary formats can be compared at the byte level.

Reporting and automation

Results can be exported to Excel, HTML, CSV, and JSON. Profiles, synchronization plans, scheduled runs, operation logs, and enterprise policy controls support repeatable use.

Packaging

The project includes MSIX and AppInstaller packaging templates, release automation, a software bill of materials, and release checks for signed distribution.
